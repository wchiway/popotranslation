# 发布检查清单

发布前逐项记录结果；未执行的项必须标记“未测试”，不能以构建成功代替。

## 构建

- [ ] 使用 Visual Studio 2026 的 MSBuild 构建 `popotranslation.slnx`，配置 `Release`、平台 `x64`。
- [ ] 运行 Core、Infrastructure、Providers 测试及 Windows 可执行检查。
- [ ] 检查构建日志无被忽略的警告（尤其是 XAML、裁剪和 Windows App SDK 警告）。
- [ ] 确认发布目录不包含 `settings.json`、DPAPI 凭据、日志、测试密钥或开发机路径。

## 运行与安全

- [ ] 在干净 Windows 11 x64 环境启动发布目录，不依赖 Visual Studio 或已安装的 Windows App SDK 开发组件。
- [ ] 托盘图标可显示；关闭设置窗口后进程和托盘仍在；托盘“退出”能结束进程。
- [ ] 第二次启动会唤醒已有实例，不产生第二个托盘图标。
- [ ] 首次启动可以新建服务配置；保存后重启仍能读取；损坏配置有明确错误且不被覆盖。
- [ ] 不填写 API Key 或模型时不会发起翻译。
- [ ] 手动连接测试只在点击后发生，并提示可能产生费用。
- [ ] 检查日志、异常消息和界面不显示 API Key、原文或译文。

## 兼容性

- [ ] 记事本、主流浏览器普通输入框和至少一个自定义输入框分别测试选区与整框读取。
- [ ] 仅 TextPattern 的多行/富文本控件可读取，无法写回时结果可复制。
- [ ] 标准单行 Edit 的自动回填在英文非 IME 布局下验证；中文输入法组合、管理员窗口和密码框如实记录限制。
- [ ] 翻译中切换窗口、移动选区或继续输入时，原内容不被覆盖，旧结果不回填。
- [ ] Explorer 重启后托盘图标恢复。
- [ ] 四种服务分别完成一次真实连接测试；检查 401、429、5xx、超时、拒绝、截断和空响应。
- [ ] 自动重定向、重试、取消和超时行为符合服务配置；取消不承诺停止服务端计费。

## 分发

- [ ] 明确发布方式是 Unpackaged 目录、安装包还是 MSIX；不要默认生成单文件 EXE。
- [ ] 如需自包含，分别验证 .NET 自包含和 Windows App SDK 自包含，记录体积和运行时依赖。
- [ ] 发布、上传安装包和推送 Git 提交需要用户明确授权；发布前不要推送未审查的本地配置或密钥。
